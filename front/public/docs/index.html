Editor guide

How articles get from a Word file to a published page and PDF on rrrreflect.

1. For authors

Send this template to every author. It explains each rule right where it applies, on a yellow background.

Download the article template (.docx)

The short version:

  • Info lines at the top, each formatted as Heading 2: Title:, Author:, Abstract: (required), Context:, Tags: (optional).
  • Sections use Heading 1, sub-sections Heading 3. Nothing else.
  • Long quotes use the style Quote.
  • Notes are real Word footnotes (References → Insert Footnote), in Chicago Notes and Bibliography style.
  • Images are not pasted in. Instead, put a line like ![Description](fig-01.jpg "Caption. © Source") where the image goes, and send the image files separately.
  • Not supported yet: tables, bullet or numbered lists, Heading 4–6.
  • Delete all yellow notes, save as LastnameFirstname.docx, and send it with the images.

2. Logging in

Everything happens in the Kirby Panel at cms.rrrreflect.org/panel. An admin creates your account (see Adding editors). The PDF editor uses the same account, and you don’t have to log in there again (see PDF layout).

3. Import an article

The import box is at the top of the Panel dashboard. The Article template (.docx) button on the right downloads the template.

  1. Click Select one .docx plus its images.
  2. Select the Word file and all its images at the same time (hold ⌘ on Mac or Ctrl on Windows while clicking).
  3. The document is checked first. If something is wrong, nothing is created and you get a list of problems (see the next section).
  4. If everything is fine, a draft is created. Click the green box to open it.

4. Fixing import errors

When the document doesn’t follow the template, the import stops and lists everything that needs fixing, all at once. Fix the Word file (or ask the author to), then import again.

MessageWhat to do in Word
Missing “Title: …” lineAdd the line at the top and give it the style Heading 2. Same for Author and Abstract.
“Author: …” is normal textSelect the info lines and apply Heading 2.
“…” is Heading 2, which is only for the info fieldsChange that heading to Heading 1.
“…” is Heading 4 (or 5)Use Heading 3 instead.
Image “fig-02.jpg” … was not selectedSelect that image file too when importing. If the name differs only in capitals (FIG-02.JPG), rename the file or fix the line in the document.
Image line not recognizedThe line must be exactly ![description](file.jpg "caption"), on its own line.
Tables / lists are not supportedTurn tables into an image; write lists as normal paragraphs.
Images are pasted into the documentDelete the pasted image and use an image line instead.
Placeholder text / template instructionsReplace the example text and delete all yellow notes.

Yellow warnings (for example an unused image, or bold text that looks like a heading) don’t stop the import. Read them and fix things in the Panel if needed.

5. Edit the article

The article page has the text on the left and the details (category, abstract, notes, tags, …) on the right.

  • Text is made of blocks. Click a block to edit it, drag blocks to reorder them, and use Add for new ones.
  • Images are image blocks. To replace one, click it and choose a different file.
  • Category decides which issue the article belongs to. Set it before publishing.
  • Save: as soon as you change something, Save and Discard appear at the top right. Only saved changes appear on the website and in the PDF.

6. Edit history

Below the text, Edit history lists the last 50 saves: when, who, and which fields changed. Click an entry to see exactly what changed: removed text in red, added text in green.

There is no undo button. To go back, copy the old text from the red lines and save it again.

7. PDF layout

Every article gets a two-column PDF layout automatically. Usually a few small fixes are enough, for example pushing a heading or image to the next column.

Finish the text first. Layout fixes are attached to paragraph positions (“the first paragraph of block 3”). If paragraphs are added or removed later, the fixes move to the wrong place and have to be redone.

  1. On the article page, click Open PDF layout editor ↗ in the right column.
  2. The editor opens in a new tab, already logged in with your Panel account.

If you open the editor some other way, for example from a bookmark, it asks you to log in. Continue with Kirby works if you are logged into the Panel; otherwise use your Kirby email and password.

Inspect: fix things by clicking

  1. Click Inspect. It turns white (“Inspect ●”).
  2. Hover over the page. The element under the mouse gets a thin black outline.
  3. Click it and choose an option. The preview updates and the change is saved right away.
  • A heading is stuck at the bottom of a column? Usually it moves automatically. If not, give it a top margin until it jumps to the next column.
  • An image doesn’t fit? Add a top margin to the paragraph before it, or a page break before the image.
  • Changes only affect this article.

CSS: fine-tuning

CSS opens a panel with the layout rules for this article, including everything you added with Inspect. Edit the values (for example 2em → 1.5em) and click Save, or press ⌘ S / Ctrl S. If a rule is unfinished (a missing }) or doesn’t start with the article’s name, nothing is saved and the bar tells you why.

Save the PDF

Click Save PDF. In the print dialog, choose Save as PDF as the destination. Chrome gives the most reliable result.

8. Review and publish

The status button at the top right of the article page (it says Draft after an import) controls who can see the article.

StatusWho can see it
DraftOnly editors (Panel and PDF editor).
In ReviewAnyone with the direct link. Not listed on the website. Use it to send the article to authors or reviewers.
PublishedEveryone. Listed on the website.

Before publishing, check the category, abstract, tags and the PDF.

9. Adding editors (admins only)

  1. In the Panel, go to Users → Add a new user.
  2. Enter their name, email and a password.
  3. Select the role “Editor”. The form selects “Admin” by default, and admins can delete users and change system settings.
  4. Click Create and send them the login details and this guide.

To remove access, delete the user. Their edits stay in the history.

10. Troubleshooting

The PDF editor asks me to log in

Open it from the article page in the Panel, or click Continue with Kirby. If you type your password: it’s the same as for the Panel, and after 10 wrong attempts login is blocked for an hour.

“Login expired, reload the page”

Your PDF editor login has expired (after one hour). If you were editing in the CSS panel, copy your CSS first. Then open the editor again from the article in the Panel, paste and save.

Someone else changed the layout at the same time

Saves only replace the rules of the article you are editing. If two people edit the same article at once, the last save wins. Check the Print CSS history.

An image is missing after the import

In the article, open the image block and choose or upload the file there.

Still stuck?

Contact the rrrreflect team with the article’s name and a screenshot.
